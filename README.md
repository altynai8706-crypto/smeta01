# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения с сохранением в PDF.

Приложение предназначено для предпринимателей, которые готовят коммерческие предложения клиентам, и офисных сотрудников, которые составляют сметы закупок и отчёты о планируемых расходах для руководителя.

## Файлы приложения

Планируемая структура (файлы приложения пока не созданы):

- `index.html` — структура страницы: поля сметы, список позиций, итог и кнопки действий.
- `styles.css` — оформление и удобное отображение на компьютере и телефоне.
- `script.js` — обработка ввода, расчёт сумм и подготовка документа к сохранению в PDF.

## Как открыть

После создания файлов приложения откройте `index.html` двойным щелчком. Приложение будет работать в браузере без установки зависимостей и запуска сервера.

## Как проверить

После реализации добавьте две позиции:

1. Количество — `2`, цена — `15 000 ₸`. Сумма позиции — `30 000 ₸`.
2. Количество — `1`, цена — `8 000 ₸`. Сумма позиции — `8 000 ₸`.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
